1. АУТЕНТИФИКАЦИЯ (/api/user, /api/auth)
================================================================================

--- 1.1. ВХОД В СИСТЕМУ (POST /api/user/login) ---

JSON для входа под админом:
{
  "email": "admin@gmail.com",
  "password": "Admin123!"
}

JSON для входа под обычным пользователем:
{
  "email": "user@gmail.com",
  "password": "User123!"
}

Описание: Возвращает JWT токен в теле ответа (поле "token") и refresh token в cookie.


--- 1.2. ОБНОВЛЕНИЕ ТОКЕНА (POST /api/auth/refresh) ---

Требуется: Cookie с refreshToken
Описание: Возвращает новый access token


--- 1.3. ВЫХОД ИЗ СИСТЕМЫ (POST /api/auth/logout) ---

Требуется: Cookie с refreshToken
Описание: Отзывает refresh token и очищает cookie

4. СТАТЬИ (/api/articles)
================================================================================

--- 4.1. СОЗДАНИЕ СТАТЬИ (POST /api/articles) ---

Content-Type: multipart/form-data

Query/Form Parameters:
- title (обязательно): Название статьи
- description (обязательно): JSON-строка с содержимым статьи (формат Quill Delta)
- categoryId (обязательно): ID категории
- videoFile (опционально): Видео файл
- files (опционально): Дополнительные файлы

Пример заполнения полей:

Поле title:
Руководство по работе с системой

Поле description (JSON в формате Quill Delta):
{
  "ops": [
    {
      "insert": "Руководство по работе с системой\n\n"
    },
    {
      "insert": "Введение",
      "attributes": {
        "bold": true,
        "header": 2
      }
    },
    {
      "insert": "\nДанное руководство содержит основную информацию о работе с системой.\n\n"
    },
    {
      "insert": "Основные функции",
      "attributes": {
        "bold": true,
        "header": 2
      }
    },
    {
      "insert": "\n• Создание статей\n• Редактирование контента\n• Управление категориями\n\n"
    },
    {
      "insert": {
        "image": "/uploads/images/example.png"
      }
    },
    {
      "insert": "\n\nДополнительная информация доступна в разделе помощи.\n"
    }
  ]
}

Поле categoryId:
1


--- 4.2. ОБНОВЛЕНИЕ СТАТЬИ (PUT /api/articles/{id}) ---

Content-Type: multipart/form-data

Query/Form Parameters:
- title (обязательно): Новое название статьи
- description (обязательно): JSON-строка с новым содержимым
- categoryId (обязательно): ID категории
- videoFile (опционально): Новый видео файл
- files (опционально): Новые дополнительные файлы
- removeFiles (опционально): Список файлов для удаления
- removeVideo (опционально): true/false - удалить видео

Пример:
Поле title: Обновленное руководство
Поле description: <JSON с обновленным контентом>
Поле categoryId: 1
Поле removeVideo: false


--- 4.3. МЯГКОЕ УДАЛЕНИЕ СТАТЬИ (PATCH /api/articles/{id}/soft-delete) ---

Query Parameters:
- isDelete (опционально, по умолчанию true): true - удалить, false - восстановить
  Пример: isDelete=true


--- 4.4. ЖЕСТКОЕ УДАЛЕНИЕ СТАТЬИ (DELETE /api/articles/delete/{id}) ---

Path Parameter:
- id: ID статьи для удаления
  Пример: /api/articles/delete/1


--- 4.5. ПОЛУЧЕНИЕ СТАТЬИ (GET /api/articles/{id}) ---

Path Parameter:
- id: ID статьи
  Пример: /api/articles/1


--- 4.6. ПОИСК СТАТЕЙ (GET /api/articles/slidebar/search) ---

Query Parameter:
- description: Поисковый запрос
  Пример: /api/articles/slidebar/search?description=руководство


--- 4.7. ЗАГРУЗКА ИЗОБРАЖЕНИЯ (POST /api/articles/upload-image) ---

Content-Type: multipart/form-data

Form Parameter:
- image: Файл изображения (jpg, png, gif, webp, макс. 10MB)


--- 4.8. ПОЛУЧЕНИЕ PDF СТАТЬИ (GET /api/articles/{id}/pdf) ---

Path Parameter:
- id: ID статьи
  Пример: /api/articles/1/pdf

Возвращает: PDF файл для скачивания

5. МОДЕРАЦИЯ (/api/moderation) - Для WRITER, MODERATOR, ADMIN
================================================================================

--- 5.1. СОЗДАНИЕ ЗАЯВКИ НА СОЗДАНИЕ СТАТЬИ (POST /api/moderation/submit/create) ---

Content-Type: multipart/form-data

Query/Form Parameters:
- title (обязательно): Название статьи
- descriptionJson (обязательно): JSON с содержимым (формат Quill Delta)
- categoryId (обязательно): ID категории
- videoFile (опционально): Видео файл
- files (опционально): Дополнительные файлы

Пример:
Поле title: Новая статья от Writer
Поле descriptionJson: {"ops":[{"insert":"Текст статьи\n"}]}
Поле categoryId: 1


--- 5.2. СОЗДАНИЕ ЗАЯВКИ НА ОБНОВЛЕНИЕ СТАТЬИ (POST /api/moderation/submit/update/{articleId}) ---

Path Parameter:
- articleId: ID существующей статьи

Form Parameters (аналогично созданию):
- title: Обновленное название
- descriptionJson: Обновленный контент
- categoryId: ID категории
- videoFile: Видео файл
- files: Дополнительные файлы


--- 5.3. ПОЛУЧЕНИЕ ЗАЯВОК НА МОДЕРАЦИЮ (GET /api/moderation/pending) ---

Требуется: Роль MODERATOR или ADMIN
Описание: Возвращает список заявок со статусом PENDING


--- 5.4. ОДОБРЕНИЕ ЗАЯВКИ (POST /api/moderation/proposals/{id}/approve) ---

Path Parameter:
- id: ID заявки

Query Parameter:
- comment (опционально): Комментарий модератора
  Пример: /api/moderation/proposals/1/approve?comment=Одобрено, отличная статья


--- 5.5. ОТКЛОНЕНИЕ ЗАЯВКИ (POST /api/moderation/proposals/{id}/reject) ---

Path Parameter:
- id: ID заявки

Query Parameter:
- reason (обязательно): Причина отклонения
  Пример: /api/moderation/proposals/1/reject?reason=Требуется доработка контента


--- 5.6. ПОЛУЧЕНИЕ ИСТОРИИ ПРОВЕРЕННЫХ ЗАЯВОК (GET /api/moderation/completed) ---

Требуется: Роль MODERATOR или ADMIN
Описание: Возвращает список заявок, проверенных текущим модератором

14. ПОДСКАЗКИ ПО РОЛЯМ
================================================================================

Роли системы (Role):
- ADMIN (id=1)     - Полный доступ
- MODERATOR (id=2) - Модерация, управление статьями
- WRITER (id=3)    - Создание заявок на модерацию
- USER (id=4)      - Базовый доступ на чтение

Роли доступа (AccessRole):
- USER (id=1)       - Базовый доступ
- GUEST (id=2)      - Гостевой доступ
